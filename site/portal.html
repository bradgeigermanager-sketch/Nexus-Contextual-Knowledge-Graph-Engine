Search graph records

Lexical search across labels, descriptions, types, edge labels, and IDs. This is not embedding-based semantic search.

Relationship inspector

Select two graph nodes to see direct edges or a shortest path through the current graph. Paths are descriptive structure, not proof of a factual relationship.

Sources, claims, and evidence

These are distinct record types. A source's presence does not mean a claim is verified; inspect the stance and verification state of each evidence link.

Submission validation preview

Paste one envelope, a JSON array, or JSONL. This browser preview checks core envelope shape, required record-specific fields, and duplicates within the submitted batch. The repository's Node validator remains the authoritative local shape validator. No records are written.

Configured web endpoints

Registry enablement means a profile is selectable by an application; it does not mean the endpoint was contacted or is currently reachable.

Implementation status registry

Status is repository-maintained metadata. CI and deployment state can change independently and should be checked against the current commit.
