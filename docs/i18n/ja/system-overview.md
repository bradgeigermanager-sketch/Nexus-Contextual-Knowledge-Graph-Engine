# システム文書 — 日本語

## 第A部 — 技術概要

### 目的と範囲
Nexus Contextual Knowledge Graph Engine は、エンティティと関係をグラフで表現し、情報源と証拠の文脈を保持し、インポートしたグラフデータを検証し、上位レベルのアーティファクトによって広い知識領域を接続するために開発中の環境です。現在のリポジトリには、単一ファイルの HTML/React アプリ、JavaScript の検証モジュール、JSON のサンプル、スキーマ、テスト、GitHub Actions による自動化が含まれます。

### 主なレイヤー
1. **正規グラフ：** ノードとエッジでエンティティと関係を表します。対応するインポート／エクスポートでは、ID と属性を可能な限り保持します。
2. **検証とデータ交換：** 構造検証、保存状態の復旧、インポート方式、形式ごとのテストを含みます。CSV は引用符付きフィールド、エスケープされた引用符、フィールド内の改行に対応します。Cypher インポーターは正規表現ベースの限定的なサブセットのみを扱い、完全な Cypher パーサーではありません。
3. **参照・証拠コーパス：** 情報源／著作、著者／出版社、主張、証拠リンクを別々のレコードとして保持します。証拠はノード、エッジ、主張、または有向の「ノード—エッジ—ノード」経路を対象にできます。情報源、主張、証拠の立場、情報源の信頼性、抽出の確信度は別の概念です。
4. **上位ネットワーク・アーティファクト層：** バージョン管理されたアーティファクトが、ノード、エッジ、主張、情報源、証拠リンク、コンテキスト、他のアーティファクトへの型付き参照をまとめます。アーティファクト間リンクは「含む」「重なる」「文脈化する」「矛盾する」「依存する」などの関係を表します。現時点の「ニューラル」は上位ネットワークのモデル化概念を指し、学習済みニューラルネットワークが実装済みという意味ではありません。
5. **テストと自動化：** Node.js テストと GitHub Actions で、対応するデータ契約とサンプルを検証します。

### 来歴と不確実性
正規オブジェクトの同一性と、アーティファクトへの所属は区別します。必要に応じて来歴、バージョン、生成方法、入力スナップショット、時間・文脈の範囲、証拠への参照を記録します。類似度、関連性、エッジ重み、確信度、情報源の信頼性、証拠の立場、事実の真偽を単一のスコアにまとめてはいけません。合成テストデータは実際の出典ではありません。

### 現在の実装状況
現在の作業ブランチには、グラフ検証とテスト、正規アーカイブとインポート例、参照・証拠コーパスのスキーマと合成例、アーティファクト層の設計・スキーマ・例・整合性テストがあります。ユーザー向けの参照編集画面、アーティファクト・エクスプローラー、広範な情報源取り込み、実際のニューラル推論や埋め込み分析は今後の作業です。最新コミットがテストに合格したと述べる前に GitHub Actions の状態を確認してください。

## 第B部 — やさしい説明

Nexus は、情報を互いにつながる部品として整理するプロジェクトです。ノードは物事や考えを表し、エッジはその間の関係を示します。情報源と証拠によって、情報がどこから来たのかを確認できます。関連する項目を大きくまとめたものを「アーティファクト」と呼びます。

たとえば、1つのアーティファクトに、報告書、テーマ、それらの関係、その関係について述べる情報源をまとめられます。アーティファクト同士も接続できます。そのため、同じ情報を何度も複製せずに、大きな情報の集まりを調べられます。

システムはまだ開発中です。一部のデータ検査、サンプル、スキーマ、自動テストは用意されています。完全な視覚編集画面、自動的なグループ発見、本物のニューラルネットワークによる分析はまだ完成していません。「合成」と表示された例は説明用であり、現実の事実を証明するものではありません。

情報を読むときは、記録に何が書かれているか、どの情報源がそれを支えるか、解釈にどれほど確信があるかを分けて考えます。意見の違いや不確実性は隠さず残します。

## コーパスローダーの更新

ローダーは、グラフ、情報源、主張、証拠、高階アーティファクトの記録を、検索インデックス付きの検証済みデータとしてまとめます。欠落ファイルや無効な参照は報告されます。これはデータ整合性の機能であり、事実を学習・証明するニューラルネットワークではありません。ブラウザー画面にはまだ接続されていません。
